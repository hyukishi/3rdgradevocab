# Civics Vocabulary Practice

Duolingo-style vocabulary practice for GitHub Pages.

## Behavior
- Definition appears first.
- Tap a card to reveal the associated word.
- Tap **Speak Answer** and say the vocabulary word.
- A wrong answer uses one of 3 chances.
- The missed card is reinserted a couple cards later, so another word appears before the retry.
- After 3 failed attempts, the word is counted as missed.
- Correct and missed totals appear when the deck is complete.

## Publish/update on GitHub Pages
1. Replace the existing repository's `index.html` with this one.
2. Commit the change to `main`.
3. If Pages is already enabled, GitHub will republish automatically.
4. Otherwise use **Settings → Pages → Deploy from a branch → main → / (root)**.

## iPhone speech recognition
Open the published HTTPS GitHub Pages URL in Safari. Tap **Speak Answer** and allow microphone access when prompted. Browser speech recognition may require an internet connection.
